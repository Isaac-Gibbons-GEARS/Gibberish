# Gibberish
This is a python program I decided to write based on a Matlab feature where the same prompt used here will give a random answer. Unlike Matlab, however, the answers can be customized to use whatever nouns, adjectives, and verbs you wish, from flaming engineers to transparent wombats.
# Commands
There are two official prompts accepted: *why* and *exit*. *Why* will generate a random answer and *exit* will terminate the session. Any other input will be met with "Meditate further".
